# QR Studio

A clean, fast and browser-based QR Code Generator built with HTML, CSS and JavaScript.

QR Studio lets you create QR codes for URLs, text, UPI payments, WhatsApp, Wi-Fi networks, contacts, email, phone numbers, SMS and map locations — directly in your browser.

## Features

- Generate QR codes instantly
- URL QR codes
- Plain text QR codes
- UPI payment QR codes
- WhatsApp chat QR codes
- Wi-Fi sharing QR codes
- Contact / vCard QR codes
- Email QR codes
- Phone number QR codes
- SMS QR codes
- Google Maps location QR codes
- Custom QR foreground color
- Custom QR background color
- Download QR code as PNG
- Copy generated QR data
- Responsive mobile-friendly UI
- Browser-based generation
- No backend required

## Supported QR Types

| Type | Description |
|------|-------------|
| URL | Create a QR code for any website |
| Text | Encode plain text or messages |
| UPI | Create a UPI payment QR |
| WhatsApp | Open a WhatsApp chat with an optional message |
| Wi-Fi | Share Wi-Fi network details |
| Contact | Create a contact / vCard QR |
| Email | Open an email composer |
| Phone | Open the phone dialer |
| SMS | Create a pre-filled SMS |
| Location | Open a location in Google Maps |

## Demo

Open the project in any modern web browser and start generating QR codes instantly.

## How to Use

1. Select the QR type.
2. Enter the required information.
3. Customize the QR color and background if needed.
4. Click **Generate QR Code**.
5. Preview the QR code.
6. Download it as a PNG or copy the encoded data.
